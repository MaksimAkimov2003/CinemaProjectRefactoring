# Android Project

## 🚀 Запуск проекта

Чтобы запустить проект на своём устройстве, выполните следующие шаги:

1. Скачайте и установите **[Android Studio](https://developer.android.com/studio)**.
2. Откройте проект в Android Studio.
3. Дождитесь, пока Android Studio закончит сборку и установку зависимостей.
4. Нажмите кнопку **Run ▶️** в верхней панели инструментов.

Проект запустится на подключённом устройстве или эмуляторе.
